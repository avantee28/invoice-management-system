# Invoice Management System

A console-based Java application to manage invoices and customer transactions efficiently.

## 🚀 Features
- Create and manage invoices
- Add items with price and quantity
- Calculate total bill
- Store invoice details in file

## 🛠️ Tech Stack
- Java (Core Java)
- OOP Concepts

## 📂 Project Structure
src/com/invoice/
- Main.java
- Invoice.java
- InvoiceService.java
- Item.java

## ▶️ How to Run
1. Compile:
   javac src/com/invoice/*.java

2. Run:
   java src/com/invoice/Main
